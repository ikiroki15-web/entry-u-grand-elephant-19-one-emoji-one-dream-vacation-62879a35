# One Emoji, One Dream Vacation

make.fun bounty entry: a program that writes exactly one emoji — a desert
island 🏝 — to `/output/entry.txt`, standing in for the trip of dreams.

## Run

```sh
node main.ts
```

Writes one emoji to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that is set). Node 22, TypeScript, no dependencies.
